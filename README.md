# Boss Auto

Boss 直聘网页自动化辅助脚本，适用于职位列表页和聊天页。

## 现有功能

### 职位列表页

- 按关键词、工作地点和屏蔽词筛选职位。
- 支持在线状态筛选；无法识别状态时可配置为跳过或保留。
- 自动滚动和翻页，收集符合条件的职位。
- 记录已加载职位，避免重复处理。
- 自动点击职位卡片中的“立即沟通”，并处理“留在此页”。
- 持续投递，直到当前职位队列全部处理完毕。
- 支持点击“暂停投递”和“继续投递”，会从当前进度继续。
- 职位操作面板支持拖动、缩小和展开。
- 悬浮工作台采用浅色青绿三栏布局，支持拖动两条分隔线调整 AI 对话、配置和日志的宽度；标题栏可切换均衡或单栏优先布局，侧栏可独立收起。拖动标题栏移动整窗，拖动右下角缩放；窄窗口自动改为纵向排列。
- 悬浮窗默认更紧凑，可缩到小窗并记住调整后的尺寸；AI 长回复在消息区独立滚动，输入框始终保留。
- AI 对话、中间配置和日志三栏均可独立收起。横向布局中收起任一栏会同步缩窄整窗，其他栏保留当前宽度；展开时恢复原宽度。小窗的纵向布局仍按面板折叠，不额外拉宽窗口。
- 窗口的四边与四角均可拖动缩放；中间配置收起后，分隔线仍可调整 AI 对话和日志的宽度。
- 日志底部显示本页累计任务统计：职位扫描去重、点击沟通、筛选跳过、匹配、失败和待处理数量；聊天页显示消息事件、已回复、略过和失败。清空日志不清空统计，刷新页面后重新计数；“已点击沟通”不代表平台确认发送成功。

### 聊天页

- 监听聊天列表中不同会话的新增或消息变化。
- 使用 MutationObserver 实时监听，同时保留低频轮询作为兜底。
- 不根据“送达”“已读”等消息状态文字触发或过滤。
- 不假设所有用户使用同一句初始话术；是否处理由新消息变化和用户缓存决定。
- 自动点击对应会话，发送设置好的文字和图片消息序列。
- 支持连续发送多条消息，消息间隔固定为 30 毫秒。
- 发送前会确认聊天输入框、发送按钮和当前会话已就绪。
- 通过聊天记录或会话列表确认文字消息是否发送成功。
- 图片选择后显示文件名，并自动读取；大于 1MB 的图片会尝试压缩。
- 点击“开始沟通”后可切换为“取消监听”。
- 聊天页只展示当前模板，模板、图片和在线状态统一在“设置”页面修改。

### 缓存与设置

- 设置保存在当前浏览器的 `localStorage` 中，刷新页面后仍然保留。
- 设置页按求职偏好、AI 助手和聊天消息分类，底部固定保存按钮，并显示未保存修改提示。
- 设置页修改后可直接点击“取消”或按 `Esc` 放弃修改并返回；顶部“返回工作台”仍会在放弃修改前确认。
- 支持创建和切换多套配置版本；每个版本独立保存职位筛选条件、在线状态规则和聊天模板。
- 旧版单配置数据会自动迁移为“默认配置”版本。
- 支持可选的 AI 职位判别：打开职位详情后，将已读取的岗位信息和用户提示词发送给 DeepSeek，AI 返回通过/跳过结果后再决定是否点击“立即沟通”。
- AI 接入配置全局共用，包括接口地址、DeepSeek 模型和 API Key；职位判断提示词、简历提示词和调用失败策略按配置版本保存。接口需要允许当前页面跨域请求。
- 当前预置 `deepseek-v4-flash`、`deepseek-flash` 和 `deepseek-v4-pro`，默认接口为 `https://api.deepseek.com/chat/completions`，暂不支持其他模型。
- DeepSeek 判别请求使用严格工具参数 Schema，固定返回 `pass`、`score`、`reason`、`risks` 四个字段，并额外进行本地字段校验。
- AI 对话中，单个工具执行失败会通过对应的工具结果把错误回传给 AI，由 AI 自行决定修正参数重试、询问用户或放弃；脚本不会自动重放成功的工具。用户取消询问会结束本轮对话，接口请求失败仍直接报错。
- `update_user_config` 只要求 AI 提交实际修改的字段，避免完整配置和大量 `null` 导致参数被截断；兼容对象、JSON 字符串及 JSON 代码块形式的工具参数；AI 对话请求不手动限制输出 token，本轮任意工具累计失败 5 次会立即终止对话，防止成功读取配置后重置计数造成无限循环。
- AI 对话可修改多轮文字消息，并通过消息 ID 保留或调整已有图片的顺序；新图片或图片替换仍需在设置页上传。
- AI Agent 提供 `search_jobs` 和 `start_deliver_jobs` 工具；前者复用职位页原生搜索框和搜索按钮并等待结果刷新，后者复用“开始投递”按钮并同步本地运行状态。搜索新关键词时会清空旧投递队列，确保后续只处理新结果。
- 单条文字消息按 Boss 当前页面规则限制为最多 999 字；设置保存、AI 工具更新和实际发送都会进行校验。
- AI 回复支持 Markdown 表格，包含表头、列对齐和单元格内的加粗、代码、链接；宽表格可在聊天气泡内横向滚动。
- 职位页和聊天页的主悬浮窗内嵌右侧操作日志区，记录版本切换、投递、AI 判断、聊天监听和异常状态；日志区支持展开、收起、滚动查看和清空。
- 已成功处理的聊天用户会写入缓存，同一用户不会重复自动发送。
- 启动聊天监听时会扫描当前已有请求，监听运行时也会检测新请求；若消息带“您是否同意”且同时包含“同意/拒绝”按钮，会打开对应会话并点击“同意”。该处理覆盖简历、电话、微信等同结构请求，且不受普通自动回复缓存影响。
- 缓存键使用会话标识，不包含“送达/已读”状态，也不依赖固定话术。
- 聊天记录缓存名称为 `boss-auto-message-records`，配置缓存名称为 `boss-auto-config`。
- 如需重新测试所有聊天用户，可在聊天页控制台执行：

```js
localStorage.removeItem('boss-auto-message-records')
```

## 使用方式

1. 在 Tampermonkey 或兼容的用户脚本管理器中安装 `boss-auto.user.js`。
2. 打开职位列表页：<https://www.zhipin.com/web/geek/jobs>。
3. 在“设置”页面填写筛选条件和聊天消息模板并保存。
4. 职位页点击“开始投递”；聊天页点击“开始沟通”。
5. 首次使用建议先少量职位、少量消息进行验证。

## 页面匹配

脚本只匹配以下页面：

- `https://www.zhipin.com/web/geek/jobs*`
- `https://www.zhipin.com/web/geek/chat*`

## 注意事项

- 脚本依赖 Boss 页面当前 DOM 结构；网站改版后部分选择器可能需要调整。
- 自动化发送前应确认模板、图片和筛选条件正确。
- 缓存保存在当前浏览器配置中；更换浏览器或用户配置后不会共享。
